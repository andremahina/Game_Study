# 🎮 Game Study - Python + Pygame

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de **explorar e compreender a mecânica de criação de jogos utilizando Python com a biblioteca Pygame**.

O foco está no aprendizado prático dos principais conceitos envolvidos no desenvolvimento de jogos, como **loop principal, eventos, física básica e renderização gráfica**.

---

## 🚀 Objetivos

* Entender como funciona o **game loop**
* Trabalhar com **eventos de teclado e mouse**
* Implementar lógica de movimentação e colisão
* Estruturar um projeto de jogo de forma organizada
* Evoluir de um protótipo simples para algo mais completo

---

## 🛠️ Tecnologias Utilizadas

* **Python**
* **Pygame**

---

## ⚙️ Funcionalidades (em desenvolvimento)

* Sistema de pontuação (planejado)

## ▶️ Como Executar o Projeto

1. Clone o repositório:

```bash id="9sd3mw"
git clone https://github.com/andremahina/Game_Study.git
```

2. Entre na pasta:

```bash id="1e6oz1"
cd Game_Study
```

3. (Opcional) Crie um ambiente virtual:

```bash id="8q4qhz"
python -m venv venv
```

4. Ative o ambiente:

* Linux/macOS:

```bash id="evntq3"
source venv/bin/activate
```

* Windows:

```bash id="2d4hqs"
venv\Scripts\activate
```

5. Instale as dependências:

```bash id="f1w3pu"
pip install pygame
```

6. Execute o jogo:

```bash id="44r7n7"
python main.py
```
